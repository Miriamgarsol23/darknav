# DarkNav

**Autonomous Crater Detection for Deep-Space Navigation via Physics-Informed Synthetic Pretraining**

Author: Miriam Garcia Sollo  
Date: June 2026

---

## The idea in one paragraph

A spacecraft navigating in deep space cannot use GPS. It must determine its position
by detecting craters in onboard camera images and matching them against a known
catalogue — a technique called Terrain Relative Navigation (TRN). Training a crater
detector with deep learning requires labelled planetary data, which is scarce for
unexplored bodies. This project addresses the scarcity by pretraining on synthetic
crater DEMs derived from the projected Navarro-Frenk-White (NFW) dark matter halo
density profile — a morphologically analogous structure. The NFW projected surface
density, when inverted, produces a radially symmetric bowl shape identical in
character to an impact crater in a Digital Elevation Map. This provides a
physics-informed weight initialisation that teaches the model crater geometry before
it ever sees real lunar data.

---

## Why this project is original

Most synthetic crater generators use hydrodynamic impact simulations (computationally
expensive) or simple Gaussian blobs (geometrically unrealistic). This project uses an
analytical physics formula from cosmology — the same NFW profile used in the author's
prior work on dark matter halo morphology in MultiDark N-body simulations — to generate
unlimited synthetic training patches in microseconds per patch with no simulation cost.

## Results

| Condition | IoU | Precision | Recall | F1 | CPU ms | ONNX ms |
|---|---|---|---|---|---|---|
| A: scratch (baseline) | 0.1333 | 0.1398 | 0.7420 | 0.2351 | 30.8 | 20.1 |
| B: ImageNet pretrained | 0.0883 | 0.0904 | 0.7946 | 0.1622 | 15.6 | 12.5 |
| C: DarkNav (NFW pretrain) | 0.0913 | 0.0955 | 0.6856 | 0.1673 | 12.7 | 9.97 |

All three conditions pass the 100 ms on-orbit inference target. ONNX Runtime achieves
under 10 ms per 128x128 patch on a standard laptop CPU. Grad-CAM analysis shows that
NFW pretraining (condition C) concentrates model attention more tightly on crater rims
compared to random initialisation, consistent with the theoretical motivation.

## Setup

```bash
git clone https://github.com/YOUR_USERNAME/darknav.git
cd darknav
python -m venv venv
source venv/bin/activate
pip install -r requirements.txt
```

## Download the dataset

```bash
cd data
zenodo_get 1133969
cd ..
python src/preprocessing.py --data_dir data --out_dir data/processed
```

## Generate synthetic dataset

```bash
python -c "from src.synthetic import generate_synthetic_dataset; generate_synthetic_dataset()"
```

## Train

```bash
python src/train.py --condition A --epochs 50 --out_dir runs
python src/train.py --condition B --epochs 50 --out_dir runs
python src/train.py --condition C_pretrain --epochs 30 --out_dir runs
python src/train.py --condition C_finetune --epochs 50 --out_dir runs \
    --nfw_checkpoint runs/condition_C/nfw_pretrain_best.pth
```

## Evaluate

```bash
python src/evaluate.py --proc_dir data/processed --runs_dir runs
```

## Run notebooks in order

```bash
jupyter lab
# Execute notebooks 00 through 04 in order
```
